# claudeai_workflow_init
用在claude.ai網頁版的開發，提供給第一個session的基本資訊

**constraints.md** 是你的環境說明書，記錄平台、本機限制、開發架構，以及現在新增的階段偵測邏輯。只要開始做東西就該帶入，是整個工作流的地基。

**bootstrap.md** 是專案的起點儀式，專門用來產出 project.md 初稿和第一份 handoff。只在你決定「這件事值得認真對待」的那一刻才需要它。

**protocol.md** 是長期協作的默契，定義 session 開場、偏移偵測、wrap-up 規則。它假設你已經在維護一個有歷史的專案，所以也只在完整專案階段才載入。
